Regulatory morphology

Kauffman's claim, tested on a plant. The genome is not a list of traits — it is a random boolean network, N genes each switched on or off by K others. Run it and it falls into a cycle it can never leave. That cycle is the phenotype. If Kauffman is right, we get discrete stable species, resistance to most mutations, and rare violent jumps, all for free, from one number: 2Kp(1−p).

The system

The genome is not a list of traits. It is a random boolean network: N genes, each one switched on or off every step by a fixed rule reading K other genes. Run it from any starting state and it must eventually repeat a state, at which point it is trapped in a cycle it can never leave. That cycle is the phenotype — the body is read off the average activity of each gene over the loop. Species, canalisation and punctuated jumps are then properties of the network, not features anyone wrote.

Parts

gene
One boolean node. Its value at step t+1 is a function only of the values of its K inputs at step t.
truth table
The rule for one gene: 2K entries, each set to 1 with probability p. Away from p = 0.5 the rules go lopsided and the network freezes.
state
The N bits at one instant. The state space is 2N, so the attractor search is capped rather than exhaustive.
transient / attractor
Iterating from a start state produces a path that must eventually revisit a state. Everything before the repeat is the transient; the loop is the attractor, of length λ. λ = 1 is a frozen point attractor.
phenotype
The mean activation of each gene over one full cycle. This is a vector in [0,1]N, and it is a property of the cycle as a set — which is why it is bit-exact regardless of where on the cycle you start reading.
body
The phenotype vector mapped onto drawing parameters: stem count, branch angle, leaf size, petal count, root depth and so on. A truncated readout is what makes two distinct attractors draw the same plant.
2Kp(1−p)
Derrida's sensitivity: the expected number of genes a single flipped gene perturbs on the next step. Below 1 the network is ordered, above 1 chaotic, and the whole design question is which side to build on.
canalisation
The fraction of mutations that change nothing about the phenotype. High canalisation is what makes a species stable enough to be an identity.

Procedure

  1. Build the genome: for each of N genes, choose K input genes and roll a 2K-entry truth table biased by p.
  2. From a random start state, iterate the whole network synchronously until a state repeats. Record the transient length and the cycle.
  3. Read the phenotype as the per-gene mean activation over that cycle, and draw the body from it.
  4. Survey: repeat from many random starts. The set of distinct attractors found is this genome's repertoire of possible bodies — Kauffman's claim is that these are the cell types, and here they are the species.
  5. Mutate: flip one truth-table entry, or rewire one input. Re-run from the same start and measure how far the phenotype moved.
  6. Sweep K × p to locate the ordered/chaotic boundary and put the current settings on it.

1 · The Kauffman raster

Every gene is a row; every synchronous update is a column; a cell is filled when that gene is on. The state space is finite, so the trajectory must eventually repeat — the moment it does, the network is trapped forever. Left of the rule is the transient; right of it, the same block of columns repeating, is the attractor. The colour is not a choice: it is this attractor's own hue, the same one its body is drawn in.

The twelve numbers that are its body

Each gene's mean activation across the cycle — how much of the loop it spends switched on — is a number in [0,1]. The first twelve are read as morphology. A bar pinned hard at either end — empty or full, drawn in ink rather than slate — is a frozen gene: it holds one value for the whole cycle, so that part of the body cannot vary at all. Note what the cycle length does to the numbers — on a λ-step cycle every parameter is forced onto a grid of multiples of 1/λ. Short cycles are not merely stable, they are quantised, and that is where the discreteness of these forms actually comes from.

4 · One mutation

Two operators, both minimal: rewire moves one input edge to a different gene; flip inverts a single entry in one gene's truth table. The starting state is held fixed, so any difference you see is the mutation and nothing else. Mutations stack — this is a lineage walking, not a coin flip.

The stability claim holds, and it holds by construction. Mean activation over a cycle is a property of the cycle as a set, so it cannot depend on the phase you enter at or on which member of the basin you started from. All 160 checks came back bit-identical — not similar, identical. That is exactly the property Wonder wants from a species: an identity that does not drift while the genome is unchanged. It also means the whole phenotype is a pure function of the attractor, so it is computed once at birth and cached, which was a requirement.

The distinctness claim is where it strains, and it strains worse as N grows. Reading only the first twelve genes throws away the rest of the network, and in the ordered regime most genes are frozen — so two genuinely different attractors routinely differ only in genes 12+ and draw the same plant. At N=24 that costs 26% of attractor pairs; at N=48, 68% of pairs are indistinguishable and the average genome supports just 1.5 visibly different bodies. The fix is cheap and should be adopted: hash all N mean-activations into the twelve parameters rather than truncating, so every gene contributes.

Canalisation tracks sensitivity, but sensitivity is not the whole story. Below 1 the frozen core absorbs most point mutations; above 1 almost every mutation reorganises the cycle, and by K=5 the cycles are hundreds of states long. But the collapse onto 2Kp(1−p) is imperfect in a specific direction, visible on the regime chart: at equal sensitivity, networks with p far from 0.5 are more canalised. K=3 at p=0.3 scores sensitivity 1.26 and 71% canalisation, while K=2 at p=0.5 scores 1.00 and only 56%. Lopsided truth tables are individually canalising — a rule that answers 1 to most of its inputs stops listening to them — and the Derrida average does not see that. Treat the number as a dial, not a law.

Recommended for Wonder: N = 32, K = 2, p = 0.40. Sensitivity 0.96, just inside ordered. Measured over eight seeds that gives 4.8 attractors and 4.1 distinct bodies per genome, 4% of pairs colliding, mean cycle 5.5, and 70% canalisation — a lineage keeps its shape through roughly seven mutations out of ten and is genuinely rebuilt by the other three. K=2 is also the cheapest genome in the study: 32 genes × (two input indices + a four-entry table) is under 100 bytes. If more inertia is wanted, N=32 K=3 p=0.25 reaches 80% canalisation with 3.6 bodies. Avoid p=0.5 with K≥4 — long cycles, no frozen core, no species. Avoid p below 0.25 at K=2 — 95% frozen, one attractor, one plant, forever.

One mapping consequence, and it is the real reason the forms come out discrete. The twelve numbers are not spread over [0,1] — they pile up at the ends. At N=32 K=2 p=0.4, 85% of them are exactly 0 or 1 (73% at p=0.5), so most morphological parameters are behaving as switches rather than dials, and a body is a combination of on/off traits. Their mean also drifts with the bias, 0.475 at p=0.5 down to 0.405 at p=0.4, so ranges need recentring if Wonder runs off-centre. In the chaotic regime the opposite happens: at K=5 only 10% of parameters are at an extreme and 74% sit between 0.3 and 0.7, because a 170-step cycle averages everything toward one half. That is why chaotic gardens look samey — every plant is the average plant.

How to read this

An attractor is where the network gets stuck. N genes with two states each gives 2N possible configurations; the update rule is deterministic, so from any start you walk a path that must eventually revisit a state, and from that moment you loop forever. The loop is the attractor, its length is the cycle length, and the walk before it is the transient.

Ordered, critical, chaotic — what they look like here. In the ordered regime (sensitivity below 1, e.g. K=2 with p near 0.25) the raster settles almost immediately and most rows are flat stripes: those are the frozen genes, 88–95% of them. Cycle lengths are 2 or 3, there are one or two attractors, and the gallery is a very short shelf of clearly different plants — sometimes a shelf of one, which is the ordered regime's failure mode. In the chaotic regime (K=4 or 5 at p=0.5) the raster never visibly settles; cycle lengths average 54 and 170 and the longest we saw was 662, and at N=64 K=5 nothing settled at all inside the cap — 60 runs out of 60 gave up. The gallery there is a crowd of middling, samey bodies, because a long cycle averages every gene toward one half: only 10% of the twelve parameters reach an extreme at K=5, against 52% at K=2. Critical is the seam between them: transients long enough to look alive, cycles short enough to have an identity, parameters still pinned at their ends.

Does "phenotype = attractor" deliver stable-but-evolvable forms? Mostly yes, with one honest caveat. Stability is exact and free. Evolvability is real: in the recommended regime 70% of point mutations leave the body untouched, which leaves three in ten that don't. The punctuation is real too — the mutation panel's own readout flips between "same plant" and "a different plant" with little in between, and the histogram of effect sizes agrees: 73% of mutations move the body by less than 0.1, 19% move it by more than 0.4, and only 8% land in the middle. A mutation either falls in the frozen core and is absorbed, or reorganises the cycle and rewrites every parameter at once. Push into chaos and that bimodality dissolves into smooth drift, which is the boring failure mode. Punctuation is a property of the ordered regime specifically. The caveat is the one in the Findings: attractor identity is finer-grained than body identity under a naive 12-gene readout, so the game would see "a new species" that looks exactly like the old one. That is a readout bug, not a failure of the idea, and it has an obvious fix.

What this does and does not tell us about Wonder. It tells us a boolean network is a viable genome format: it is cheap (a few hundred bytes), it is computed once at birth and cached — the attractor search is a few hundred synchronous updates, done once, never per tick — and it produces discrete forms without a lookup table of fourteen hardcoded shapes. It does not tell us anything about fitness. Nothing here selects; every attractor is equally good. Wonder's real problem, named in the ecology audit, is that it has no fitness function, and a boolean-network genome does not supply one — it supplies the raw material a fitness function would act on. It also says nothing about whether these twelve parameters are the right twelve; that is a separate art problem, and the reagent bench argues the parameters should come from metabolism rather than being declared.

What the player would actually see. A lineage that keeps its recognisable shape for many generations — the same silhouette on the same hillside, season after season, because seven in ten of its mutations do nothing visible. Then, rarely, a seedling comes up wrong: different branching, different colour, a bloom where there was none. Not a nudge — a different plant, all at once, from one bit. That is the "witness adaptation" moment Wonder is currently unable to produce, because a flat float genome can only ever drift smoothly, and smooth drift is invisible at the timescale a player watches. The cost is that the twelve parameters are no longer independently steerable by a designer; you tune the regime, not the plant.

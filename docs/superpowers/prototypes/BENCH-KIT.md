# The bench kit — shared spec for Wonder's ecology prototypes

Every bench in this suite is a **single self-contained HTML file** that inlines
everything below, so the whole set reads as one instrument rather than six
unrelated pages. Copy the CSS and the helpers verbatim; vary only the content.

**Hard constraints, all benches:**

- No external requests of any kind — no font CDNs, no script CDNs, no images.
  Inline everything. (These get published behind a strict CSP.)
- No `<!DOCTYPE>`, `<html>`, `<head>` or `<body>` tags — the file starts with
  `<style>` and contains only page content. It gets wrapped at publish time.
- No `Math.random()` and no `Date.now()` in any model path. All randomness comes
  from the seeded `makeRng` below, so a seed always reproduces a run exactly.
  (Wall-clock is fine for animation only.)
- Must render correctly in **both** light and dark. Style through the tokens; never
  put component styles inside the media query.
- `document.body.scrollWidth` must never exceed the viewport. Wide content
  (tables, graphs, logs) gets its own `overflow-x: auto` container.
- Respect `prefers-reduced-motion`.
- Every non-void element closed, every attribute double-quoted, keyboard focus
  visible on every control.

## 1 · Design tokens (copy exactly)

rules, monospace labels, a serif for display. The chrome is deliberately quiet so
that the only saturated colour on the page is *generated by the model*. That is
the thesis of the whole suite — colour is earned, not decorated. Do not add an
accent colour beyond `--slate`.

## 2 · The control rail (every bench uses this)

Parameters live in a persistent rail. Each control shows its **live value** and,
where it matters, a one-line note on what moving it does. A slider nobody can
interpret is not a parameter, it is a mystery.

## 3 · Shared helpers (copy exactly)

```js
// mulberry32 — matches src/core/rng.ts. Warmed 12 draws because the first draw
// correlates across nearby seeds; this project has been bitten by that before.
function makeRng(seed) {
  let a = seed >>> 0;
  const f = function () {
    a |= 0; a = (a + 0x6D2B79F5) | 0;
    let t = Math.imul(a ^ (a >>> 15), 1 | a);
    t = (t + Math.imul(t ^ (t >>> 7), 61 | t)) ^ t;
    return ((t ^ (t >>> 14)) >>> 0) / 4294967296;
  };
  for (let i = 0; i < 12; i++) f();
  return f;
}

// OKLCH -> #rrggbb (Ottosson). We convert ourselves rather than handing oklch()
// to canvas so swatches and sprites can never disagree. Chroma is walked down
// until it fits sRGB, because clipping channels would shift the hue and hue is
// carrying information in these benches.
function oklch(L, C, H) {
  L = Math.max(0, Math.min(1, L));
  const rad = (H * Math.PI) / 180;
  const lin = (c) => {
    const a = c * Math.cos(rad), b = c * Math.sin(rad);
    const l_ = L + 0.3963377774 * a + 0.2158037573 * b;
    const m_ = L - 0.1055613458 * a - 0.0638541728 * b;
    const s_ = L - 0.0894841775 * a - 1.2914855480 * b;
    const l = l_ * l_ * l_, m = m_ * m_ * m_, s = s_ * s_ * s_;
    return [ 4.0767416621*l - 3.3077115913*m + 0.2309699292*s,
            -1.2684380046*l + 2.6097574011*m - 0.3413193965*s,
            -0.0041960863*l - 0.7034186147*m + 1.7076147010*s];
  };
  let c = Math.max(0, C), v = lin(c);
  for (let i = 0; i < 24 && !v.every((x) => x >= -0.0005 && x <= 1.0005); i++) v = lin(c *= 0.92);
  const enc = (x) => {
    x = Math.max(0, Math.min(1, x));
    const s = x <= 0.0031308 ? 12.92 * x : 1.055 * Math.pow(x, 1 / 2.4) - 0.055;
    return Math.round(Math.max(0, Math.min(1, s)) * 255);
  };
  return "#" + v.map(enc).map((n) => n.toString(16).padStart(2, "0")).join("");
}

// Build a slider into a rail. onInput receives the numeric value.
function slider(host, opts) {
  const wrap = document.createElement("div"); wrap.className = "ctrl";
  const row = document.createElement("div"); row.className = "row";
  const lab = document.createElement("label"); lab.textContent = opts.label;
  const val = document.createElement("span"); val.className = "val";
  const input = document.createElement("input");
  input.type = "range";
  input.min = opts.min; input.max = opts.max; input.step = opts.step || 1;
  input.value = opts.value;
  lab.htmlFor = input.id = "c_" + opts.label.replace(/\W+/g, "_");
  const fmt = opts.fmt || ((v) => String(v));
  const paint = () => { val.textContent = fmt(+input.value); };
  input.addEventListener("input", () => { paint(); opts.onInput(+input.value); });
  row.appendChild(lab); row.appendChild(val);
  wrap.appendChild(row); wrap.appendChild(input);
  if (opts.hint) {
    const h = document.createElement("div"); h.className = "hint"; h.textContent = opts.hint;
    wrap.appendChild(h);
  }
  host.appendChild(wrap); paint();
  return input;
}
```

## 4 · Voice and required structure

`docs/WRITING-STANDARD.md` governs. Read it before writing page copy; the rules
below are the bench-specific additions to it.

**Every bench opens with a `.spec` block**, before the instrument, containing:

1. `<h2>The system</h2>` and one literal paragraph — what the model computes.
2. `<h3>Parts</h3>` — a `<dl class="defs">` defining every term the page uses,
   with types and ranges. If a word appears in a heading, a slider label or a
   readout, it is defined here.
3. `<h3>Procedure</h3>` — an `<ol class="proc">` of the algorithm in execution
   order, numbered.
4. `<h3>What is on this page</h3>` — a `<dl class="defs">` naming each panel and
   what it shows.

Findings come last, never before the definitions. Copy the `.spec` CSS from any
existing bench.

Write the page copy the way a working scientist labels their own bench: plain,
specific, willing to say what failed. Name the source of a mechanism where there
is one ("Kauffman's RAF condition", "Holland's tag matching"). Never oversell —
if a parameter regime produces mush, the page should say it produces mush. Each
bench ends with a short honest note on **what this does and does not tell us
about Wonder**, and on **what the player would actually see** if the mechanism
shipped, because a mechanism nobody can perceive is not a feature.

## 5 · Self-verification before you finish

Playwright is already a dev dependency of this repo. Write a throwaway script at
the repo root, run it, fix what it finds, then delete the script. Check:

1. no console errors and no page errors,
2. `document.body.scrollWidth <= window.innerWidth` at 1280px **and** at 430px,
3. every canvas you draw to is actually painted (sample `getImageData`, not zero),
4. moving each parameter to its extremes changes the readouts and does not throw,
5. the same seed twice produces identical numbers.

Report what you found and fixed.
